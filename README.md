# 破茧 · 短视频热门内容同质化数据分析

> 困住我们的"信息茧房"，能不能由懂数据的人亲手打破？
> 这是我的第一个完整数据分析项目，也是我用数据回答入学之问的第一步。

## 问题

短视频平台上反复出现一个词——"信息茧房"：算法比我们更懂我们爱看什么，也悄悄把我们围进同质化内容的围墙。

茧房的形成有两端：**需求侧**（算法给每个人投喂偏好内容）和**供给侧**（热门内容本身是否高度同质化）。本项目从供给侧入手，用公开数据检验三个问题：

1. **类型分布**——谁在霸榜？热门内容的类型是否高度集中？
2. **流量集中度**——二八定律是否成立？少数视频是否吃掉多数流量？
3. **时间演化**——霸榜能持续多久？同一内容是否被反复"复读"？

## 数据集

| 项目 | 说明 |
|---|---|
| 数据 | Trending YouTube Video Statistics（YouTube 美国区热门视频榜单） |
| 来源 | Kaggle 公开数据集（GitHub 镜像：the-codingschool/TRAIN-datasets） |
| 规模 | 40,949 条上榜记录 · 6,351 个唯一视频 · 2,207 个频道 |
| 时间跨度 | 2017-11-14 ~ 2018-06-14（约 7 个月） |
| 字段 | 视频 ID、上榜日期、标题、频道、类别、播放/点赞/评论数等 16 列 |

## 核心结论

**① 类型高度集中**：Entertainment、Music、Howto & Style 三类合计占热门榜 **50.3%**——一半榜单被三种内容占据。

**② 二八定律近乎精确成立**：头部 **20%** 的视频吃掉 **79.4%** 的播放量；而尾部 50% 的视频合计仅占 **4.8%**。流量分布的陡峭程度远超直觉。

**③ 榜单是"复读机"**：一个视频上榜天数的中位数为 **6 天**，最长 29 天；霸榜 ≥7 天的"钉子户"视频（2,528 个）占去了 **72.8%** 的播放量。

**综合判断**：热门内容的供给侧高度同质化——少数类型、少数视频、长期霸榜。当"多数人的注意力"被极少数内容占据，个体接触多元内容的入口就被压缩了。这是茧房得以存在的土壤。

## 局限性（诚实声明）

- YouTube 数据 ≠ 抖音数据，结论不能直接平移到国内平台；但"热门榜单集中"作为平台算法的普遍现象，具有参考性。
- 数据时间为 2017-2018 年，反映的是短视频生态早期的供给侧结构。
- 本项目只检验了供给侧；需求侧（算法个性化投喂）需要用户行为数据，超出公开数据集的范围。
- 播放量集中 ≠ 必然形成个体茧房，但它是必要的中间证据链。
